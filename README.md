# RandomChoice

![Build Status](https://github.com/Feriel080/RandomChoice/workflows/Build%20Installer/badge.svg)

A simple cross-platform app using flutter as front-end and python (fast API) for backend. Useful for decision-making, raffle draws, or random picks!

***To download the app's latest release:***

[![Download Latest Release](https://img.shields.io/badge/Download-Latest_Release-green?style=for-the-badge&logo=github)](https://github.com/Feriel080/RandomChoice/releases/download/v1.0/RandomChoice.exe)


## Features ✨

* Add custom items to a list
* Randomly select an item with a button tap
* Clean and intuitive UI
* Cross-platform (works on Android, iOS, Windows, Linux, and macOS)


## **🚀 Getting Started**

### **Prerequisites**

* Flutter SDK ([Installation Guide](https://docs.flutter.dev/get-started/install))
* Dart (comes with Flutter)
* Git (for cloning the repository)


### **📥 Clone the Repository**

```
git clone https://github.com/yourusername/random-list-picker.git
cd random-list-picker
```


### **🛠 Install Dependencies**

```
flutter pub get
```


### **▶ Run the App**

```
flutter run
```
